# Voice samples

Text Quinn wrote themselves, without AI: Slack messages, Notion notes, comments, paragraphs
rewritten from a draft. Read these before writing. Copy the rhythm, the sentence length, the
words Quinn reaches for and how they mix Vietnamese with English terms. Never copy the content.

Add 5–10 samples, VI first. Each one: where it came from, then the text as written, typos
included. Remove anything internal (company, client, people's names) before adding it.

While this file has no samples, say so in the review.
