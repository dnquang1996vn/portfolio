# Vietnamese that mirrors English

The usual failure is not a wrong word. It is an English sentence with Vietnamese words in the
same order. Every example below was on this site and Quinn rejected it.

## The test

Cover the English. Read the Vietnamese aloud. If you have to translate it back to English to
understand it, rewrite it from the meaning.

## Patterns

| Pattern | Was on the site | Now |
|---|---|---|
| Noun-for-noun rendering of an English role phrase | "Tôi dẫn dắt kỹ thuật tại Webprovise và thiết kế kiến trúc Welle" (I lead engineering at... and architected...) | "Tôi là Quinn, tech lead ở Webprovise. Tôi là người thiết kế kiến trúc cho Welle" |
| English image kept literally | "từ schema đầu tiên đến bản release, tôi vừa viết code vừa dẫn dắt kỹ thuật" | "Từ lúc thiết kế đến khi lên production, tôi vừa trực tiếp code vừa dẫn dắt team" |
| "where X meets Y" | "ở điểm giao giữa viết code và dẫn dắt kỹ thuật" | Say both things: "vừa trực tiếp code vừa dẫn dắt team" |
| "stay close to the code" | "ở gần code" | "vẫn trực tiếp code" |
| "in the loop" | "khi có LLM trong vòng lặp" | "khi có LLM tham gia" |
| "earns its place" | "đúng chỗ nó xứng đáng" | "ở chỗ nó thật sự có ích" |
| "under HIPAA", "under real constraints" | "dưới HIPAA", "trong điều kiện thật" | "theo chuẩn HIPAA", "với ràng buộc thật" |
| "are all welcome", "I'd love to hear" | "đều được chào đón", "Tôi rất muốn nghe" | "cứ nhắn cho tôi" |
| "a useful start" | "là khởi đầu hữu ích" | "thì tôi dễ trả lời hơn" |
| Abstract noun as subject | "Một hồi quy làm hỏng build" | "Có regression là build fail" |
| Passive with "được" where VI uses active | "được cùng bộ test bao phủ" | "chạy chung bộ test" |
| False friend | "Mã hóa giá và quy định" for "Encoded pricing rules" (mã hóa = encrypt) | "Đưa giá và quy định theo từng bang vào hệ thống" |
| False friend | "viết lại" for "writing it down" (viết lại = rewrite) | "ghi lại" |
| "ship", "deliver", "launch" as one verb | "Ra mắt bảng dữ liệu", "Giao marketplace" | "Làm bảng dữ liệu", "Làm marketplace" |
| "build" as "xây" or "làm" | "Tôi xây", "Có sản phẩm cần xây?", "Bạn đang làm gì" | Keep "build": "Tôi build", "Có sản phẩm cần build?", "Bạn đang build gì" |
| "lead" as "dẫn" or "dẫn dắt" + thing | "dẫn frontend Bamboo" | "lead frontend Bamboo"; "dẫn dắt team" for people |
| Tech term translated | "ảo hóa", "đặc tả", "bộ khẳng định", "header dính", "hợp đồng lõi" | virtualize, spec, assertion, sticky header, contract |
| Inflated or brochure word | "Hành trình", "Khám phá", "người ta tin dùng", "mục rữa theo thời gian" | "Quá trình làm việc", "Xem chi tiết", "có người dùng thật", "nát dần" |
| Slogan flattened into a plain sentence | "Làm xong thì ghi lại." for the section title "Building things. Writing it down." | "Build. Rồi viết ra." Keep the two beats; a title has to hook |
| "đội" | "dẫn đội", "đội London" | "team" |
| Form-speak | "Trường này là bắt buộc.", "Nhập một địa chỉ email hợp lệ." | "Bạn chưa điền mục này.", "Email chưa đúng định dạng." |

## What natural VI on this site looks like

- Short lead-in, colon, then the point: "Chín năm, ba lĩnh vực, một thói quen: đã nhận việc gì thì theo đến cùng."
- Topic first, comment after: "Tin nhắn nào tôi cũng đọc."
- Everyday verbs: làm, dùng, sửa, chạy, đụng vào, vướng.
- Drop the subject when it is obvious. Drop "một" and "những" where English forced "a" and "the".
